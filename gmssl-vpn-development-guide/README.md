# 基于 OpenVPN 与 GmSSL 的 GM/T 0024-2023 SSL VPN 开发指南

> 版本：v1.0 · 发布日期：2026-07-19 · 标准基线：GM/T 0024-2023 · 状态：四章正文与配套附录已完成

## 指南目标

本指南面向第一次接触国密 SSL VPN、但具备基础系统开发能力的研发人员。

指南帮助读者理解 OpenVPN、GmSSL 与 GM/T 0024-2023 之间的关系，完成 GMSSL VPN 的总体设计，沿着一条清晰的开发路线形成完整系统，并建立能够逐项复核的标准符合性证据。

本指南的完成目标不是“接通一条国密连接”，而是同时形成：

```text
符合标准的密码与 TLCP 协议
+ 完整的 VPN 网络、会话和访问控制能力
+ 密码部件、安全管理、日志与自检
+ 可追踪、可复核的验证证据
```

## 使用边界

- 本指南以 GM/T 0024-2023 为技术基线；涉及条款判定时，以合法取得的标准正式文本为准；
- 指南给出完整的设计、开发和验证路线，不替代产品检测，也不以局部互通结果代替符合性结论；
- OpenVPN 和 GmSSL 是工程与密码协议基础。进入产品实现的代码必须固定来源版本，完成源码审查、差异管理、测试和持续维护；
- 标准原文、上游代码和本指南是不同的作品。引用或分发时应分别遵守对应的版权和许可要求，详见[附录：来源与许可边界](appendix/sources-and-license-boundary.md)。

本指南新增文字与图表按 [GPL-2.0-only](LICENSE.md) 发布；被引用的标准名称、上游项目名称和链接不改变其各自权利归属。

## 写作原则

1. 每章只解决一个核心问题。
2. 先展示整体，再解释必要组成。
3. 正文沿系统形成过程展开，不按模块堆砌百科知识。
4. API、命令、配置和源码索引放入附录或配套示例。
5. 每个开发阶段都应产生一个可观察、可验证的系统结果。
6. 只归纳标准要求并标注条款，不复制标准原文。

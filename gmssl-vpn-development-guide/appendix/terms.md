# 附录 E：核心术语

| 术语 | 本指南中的含义 |
|---|---|
| GMSSL VPN | 按 GM/T 0024-2023 设计的 SSL VPN 目标系统，不是 GmSSL 库中的现成产品名称 |
| TLCP | 传输层密码协议，负责身份认证、安全参数协商、密钥建立和记录保护 |
| VPN 接入会话 | 服务端为已认证用户建立的访问安全上下文，绑定身份、虚拟地址、策略和有效 TLCP 连接 |
| TLCP 连接 | 具有当前/未决读写状态、协商参数和记录保护状态的安全传输连接 |
| 密码状态 | 与 TLCP 连接关联的主密钥、工作密钥、方向参数及其生命周期状态 |
| 双证书 | 签名证书与加密证书分离使用的证书模型，分别服务于签名认证和加密/密钥交换 |
| 密码部件 | 独立执行密码运算并保护密钥和关键数据的软硬件边界；产品路径需满足标准对独立密码部件的要求 |
| 工作密钥 | 由主密钥、客户端随机数和服务端随机数按标准计算，用于记录加密和完整性保护的方向性密钥 |
| 保护域 | 网关—网关模式中与 TLCP 连接绑定的本地和对端网络/传输层范围 |
| `application_data` | TLCP 应用数据记录；本指南在客户端—服务端模式中用它承载自定义 VPN 载荷 |
| `site2site(80)` | 标准为网关—网关模式定义的记录类型，包含 command 和 data 两类内容 |
| 符合性证据 | 能把标准条款、设计、实现、验证方法和实际结果连接起来的可复核材料 |
